# irma-fortune-teller
Welcome to Irma’s Fortune Telling! 🔮

Ever wondered what the future has in store for you?

Well, Irma claims to know. Unfortunately, she also claims that pigeons can predict stock market crashes.

Irma’s Fortune Teller is a small, humorous Python project that generates absurd, random predictions about your future. Answer a few questions, consult the stars, and discover your destiny!

What to expect:

* Random and ridiculous fortune predictions.
* Dramatic messages and fake mystical revelations.
* An extremely questionable fortune teller.
* A surprisingly expensive consultation.

Disclaimer: This project is purely for fun and educational purposes. It is not a real fortune-telling tool, and its predictions have no scientific basis. Please do not base important life decisions on the advice of a Python script. Especially one that charges $500.

Built with: Python’s standard library (random and time).

No external dependencies required.
